Tìm hiểu về Accordion

topic 1 - HTML

HTML (viết tắt của từ HyperText Markup Language, hay còn gọi là "Ngôn ngữ Đánh dấu Siêu văn bản") là ngôn ngữ được thiết kế để tạo nên các trang web trên World Wide Web.

topic 2 - CSS

CSS là chữ viết tắt của Cascading Style Sheets, là ngôn ngữ định kiểu cho các phần tử HTML giúp trang web hiển thị đẹp và rõ ràng hơn.

topic 3 - jQuery

jQuery là thư viện JavaScript giúp đơn giản hóa thao tác DOM, xử lý sự kiện, hiệu ứng và Ajax.
